# Hermes Appointment Setter Template

A reusable, self-improving AI Appointment Setter built on Hermes Agent by Nous Research.

**Features:**
- 24/7 autonomous booking via chat/voice
- Google Calendar integration
- Automatic logging to Google Sheets
- Lead qualification
- Follow-up automation
- Self-improving skills

## Quick Start for New Clients

1. Run: `hermes profile create client-name --clone appointment-template`
2. Switch to the new profile: `hermes profile switch client-name`
3. Paste the **Client Onboarding Prompt** (see SETUP.md)
4. Hermes will set up everything automatically

Made for selling as a done-for-you service.
