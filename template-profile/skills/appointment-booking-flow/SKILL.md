**Full Process**:
1. Warm greeting and initial qualification
2. Deep qualification using checklist
3. Real-time calendar availability check
4. Propose 2-3 best time slots
5. Handle questions or objections
6. Full confirmation of details
7. Create Google Calendar event
8. Log complete record to Sheets
9. Send confirmation message to client
