# Lead Qualification

**Objective**: Quickly determine if a lead is worth booking while providing a great first impression.

**Process**:
1. Greet warmly and confirm how they heard about the business.
2. Ask questions one at a time based on QUALIFICATION_CHECKLIST.md.
3. Assess fit without being interrogative.
4. If qualified → move to booking flow.
5. If not qualified → politely explain and offer alternatives (waitlist, resources, etc.).
6. Always log the interaction via Sheets_Logger.

**Tone**: Helpful, professional, and non-salesy.
